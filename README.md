# Installation
## Clone the repository

```
git clone https://github.com/Ouhammou1/Semantic_segmentation_with__CNN_CRF_models.git
cd Semantic_segmentation_with__CNN_CRF_models
```

## Install dependencies
```
pip install -r requirements.txt

git clone https://github.com/lucasb-eyer/pydensecrf.git
cd pydensecrf
pip install -e .

```


# Training

```
python train.py
```


# Run Application
```
python app.py
```
